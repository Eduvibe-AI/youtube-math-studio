함수의 극한의 성질 진위판단 (반례 없는 치환법)

"시험장에서 반례 떠올리려다 시간 날리지 마라!"
합답형(ㄱ, ㄴ, ㄷ) 문제의 참/거짓을 3초 만에 꿰뚫어 보는 단 1가지 필연적 해법:
수렴하는 덩어리를 $h(x)$로 치환하는 법칙 · 사칙연산 분배 가능 조건 · 분모가 0이 되는 치명적 함정 필터링을 동적 진위판정 시뮬레이터로 정복합니다.

⭐ 함수의 극한 진위판단 3단계 의사결정 알고리즘
1단계: 수렴 덩어리 치환
$f(x)+g(x) = h(x)$
$\lim h(x)$는 확실한 수렴값
2단계: 대상 함수 표현
$g(x) = h(x) - f(x)$
수렴 함수들의 연산으로 재구성
3단계: 분모 0 필터링
분모 $\neq 0$ 확인
0이 될 수 있으면 즉시 거짓!
판정 결과 도출
3초 만에 합답형 완료
반례 없이 완벽한 수학적 증명
💡 대표 합답형 명제를 선택하면 치환 대수식과 참/거짓 판정 논리가 다이어그램으로 나타납니다.
🎯 평가원 대표 합답형 명제 선택 (Proposition)
📊 실시간 판정 리포트 (Live Verdict)
• 명제: $\lim f$ 와 $\lim(f+g)$ 수렴 $\implies \lim g$ 수렴
• 치환: $f(x) + g(x) = h(x) \implies g(x) = h(x) - f(x)$
• 판정: ✔ 참 (True)
• 근거: 수렴하는 두 함수의 뺄셈이므로 무조건 수렴

📸 10단계 판서 캡처 & 타임라인별 상세 해설

1단계 [00:20] 합답형 문제의 어려움과 반례의 한계

시험장에서 반례를 떠올리려다 시간만 낭비하는 기존 학습법의 한계를 지적합니다.

2단계 [01:10] 함수의 극한 기본 성질의 전제 조건

두 함수가 모두 수렴할 때만 사칙연산 기호가 안으로 들어갈 수 있다는 대전제를 확인합니다.

3단계 [02:20] 나눗셈의 치명적 함정: 분모는 0이 아니어야 한다

나눗셈에서 분모의 극한값이 0이 될 수 있는 가능성이 존재하는 순간 거짓이 됨을 강조합니다.

4단계 [03:30] 반례 없는 마법의 무기: 치환법 h(x)의 도입

수렴한다고 주어진 복잡한 덩어리 식 전체를 하나의 새로운 함수 h(x)로 치환하는 발상을 배웁니다.

5단계 [04:40] 실전 예제 1: $\lim f$ 와 $\lim (f+g)$ 가 수렴할 때

g(x) = h(x) - f(x)로 표현되므로 수렴 - 수렴 = 수렴 (참!)임을 명쾌하게 증명합니다.

6단계 [05:50] 실전 예제 2: $\lim f$ 와 $\lim (fg)$ 가 수렴할 때

g(x) = k(x)/f(x)로 분모에 f(x)가 들어가므로 lim f(x)=0일 가능성 때문에 거짓임을 보입니다.

7단계 [07:00] 실전 예제 3: 분수형 극한 $\lim \frac{g}{f}$ 가 수렴할 때

역수를 취하거나 곱할 때 분모의 0 수렴 가능성 유무를 1초 만에 걸러내는 필터링 기법을 배웁니다.

8단계 [08:10] 실전 예제 4: 대소 관계와 샌드위치 정리

부등식에서 극한을 취할 때 등호가 붙는 원리와 수렴값의 일치 여부를 점검합니다.

9단계 [09:20] 평가원 기출 ㄱ, ㄴ, ㄷ 30초 컷 시연

수능 평가원 실제 기출문제를 치환법 하나만으로 암산으로 완벽하게 해결합니다.

10단계 [10:20] 진위판정 의사결정 순서도 총정리

시험장에서 써먹는 3단계 알고리즘: 치환 -> 표현 -> 분모 점검을 마스터합니다.

📐 수학적 원리 & 치환 증명법

1. 교과서 함수의 극한 기본 성질 (사칙연산 법칙)

$$\lim_{x \to a} f(x) = \alpha, \quad \lim_{x \to a} g(x) = \beta \quad (\alpha, \beta \text{는 실수})$$

일 때 다음이 성립합니다:

  • $\lim [f(x) \pm g(x)] = \alpha \pm \beta$
  • $\lim [f(x) g(x)] = \alpha \beta$
  • $\lim \frac{f(x)}{g(x)} = \frac{\alpha}{\beta} \quad (\mathbf{\beta \neq 0})$

2. 치환법의 절대성 증명

$\lim f(x) = \alpha$, $\lim [f(x)+g(x)] = \gamma$일 때, $f(x)+g(x) = h(x)$라 두면 $\lim h(x) = \gamma$입니다.

우리가 구하고자 하는 함수 $g(x) = h(x) - f(x)$이므로:

$$\lim g(x) = \lim [h(x) - f(x)] = \lim h(x) - \lim f(x) = \gamma - \alpha$$

두 수렴하는 함수의 차는 항상 수렴하므로 명제는 100% 참이 됩니다!
