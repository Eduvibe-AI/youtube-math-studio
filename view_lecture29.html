⚡ 제29강 · 수능 수학 II 함수의 극한 킬러 실전 비기

함수의 극한의 성질 진위판단 (반례 없는 치환법)

"시험장에서 반례 떠올리려다 시간 날리지 마라!"
합답형(ㄱ, ㄴ, ㄷ) 문제의 참/거짓을 3초 만에 꿰뚫어 보는 단 1가지 필연적 해법:
수렴하는 덩어리를 $h(x)$로 치환하는 법칙 · 사칙연산 분배 가능 조건 · 분모가 0이 되는 치명적 함정 필터링을 동적 진위판정 시뮬레이터로 정복합니다.

⭐ 함수의 극한 진위판단 3단계 의사결정 알고리즘
1단계: 수렴 덩어리 치환
$f(x)+g(x) = h(x)$
$\lim h(x)$는 확실한 수렴값
2단계: 대상 함수 표현
$g(x) = h(x) - f(x)$
수렴 함수들의 연산으로 재구성
3단계: 분모 0 필터링
분모 $\neq 0$ 확인
0이 될 수 있으면 즉시 거짓!
판정 결과 도출
3초 만에 합답형 완료
반례 없이 완벽한 수학적 증명
💡 대표 합답형 명제를 선택하면 치환 대수식과 참/거짓 판정 논리가 다이어그램으로 나타납니다.
🎯 평가원 대표 합답형 명제 선택 (Proposition)
📊 실시간 판정 리포트 (Live Verdict)
• 명제: $\lim f$ 와 $\lim(f+g)$ 수렴 $\implies \lim g$ 수렴
• 치환: $f(x) + g(x) = h(x) \implies g(x) = h(x) - f(x)$
• 판정: ✔ 참 (True)
• 근거: 수렴하는 두 함수의 뺄셈이므로 무조건 수렴

📐 수학적 원리 & 치환 증명법

1. 교과서 함수의 극한 기본 성질 (사칙연산 법칙)

$$\lim_{x \to a} f(x) = \alpha, \quad \lim_{x \to a} g(x) = \beta \quad (\alpha, \beta \text{는 실수})$$

일 때 다음이 성립합니다:

  • $\lim [f(x) \pm g(x)] = \alpha \pm \beta$
  • $\lim [f(x) g(x)] = \alpha \beta$
  • $\lim \frac{f(x)}{g(x)} = \frac{\alpha}{\beta} \quad (\mathbf{\beta \neq 0})$

2. 치환법의 절대성 증명

$\lim f(x) = \alpha$, $\lim [f(x)+g(x)] = \gamma$일 때, $f(x)+g(x) = h(x)$라 두면 $\lim h(x) = \gamma$입니다.

우리가 구하고자 하는 함수 $g(x) = h(x) - f(x)$이므로:

$$\lim g(x) = \lim [h(x) - f(x)] = \lim h(x) - \lim f(x) = \gamma - \alpha$$

두 수렴하는 함수의 차는 항상 수렴하므로 명제는 100% 참이 됩니다!
