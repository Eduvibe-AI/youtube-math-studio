1. [공통(수학Ⅰ·수학Ⅱ) / 2점] 정답 ③
▶ 출제의도 : 지수법칙을 이용하여 식의 값을 구할 수 있는가?
[풀이] $\sqrt[3]{3}\times 9^{\frac{1}{3}} = 3^{\frac{1}{3}}\times (3^2)^{\frac{1}{3}} = 3^{\frac{1}{3}}\times 3^{\frac{2}{3}} = 3^{\frac{1}{3}+\frac{2}{3}} = 3^1 = 3$
2. [공통(수학Ⅰ·수학Ⅱ) / 2점] 정답 ④
▶ 출제의도 : 미분계수의 정의를 이용하여 미분계수를 구할 수 있는가?
[풀이] $f'(x)=3x^2-5$이므로 미분계수의 정의에 의하여 $$\lim_{h\to 0}\dfrac{f(2+h)-f(2)}{h} = f'(2) = 3\times 2^2 - 5 = 7$$
3. [공통(수학Ⅰ·수학Ⅱ) / 3점] 정답 ④
▶ 출제의도 : 등비수열의 일반항을 이용하여 양수 $k$의 값을 구할 수 있는가?
[풀이] 등비수열 $\{a_n\}$의 첫째항과 공비가 모두 양수 $k$이므로 $a_n=k^n$이다. $$\dfrac{a_4}{a_2}+\dfrac{a_2}{a_1} = k^2 + k = 20$$ $k^2+k-20 = (k+5)(k-4) = 0$에서 $k>0$이므로 $k=4$이다.

▶ 출제의도 : 모집단과 표본평균의 분산 사이의 관계를 이해하고 상수의 값을 구할 수 있는가?
[풀이] 모집단의 확률변수를 $X$라 하면 $\mathrm{E}(X)=6$이고, $$\mathrm{V}(X) = \dfrac{16+4+0+4+16}{5} = 8$$ 크기가 $n=2$인 표본평균 $\bar{X}$의 분산은 $\mathrm{V}(\bar{X})=\dfrac{\mathrm{V}(X)}{2}=4$이다. $\mathrm{V}(a\bar{X}+5)=a^2\mathrm{V}(\bar{X})=4a^2=64$에서 $a^2=16$이므로 양수 $a=4$이다.
28. [확률과 통계 / 4점] 정답 ②
▶ 출제의도 : 중복조합을 이용하여 주어진 부등식과 약수 조건을 만족시키는 함수의 개수를 구할 수 있는가?
[풀이] 조건 (가), (나)에서 $f(1)\le f(6)$이고 $f(1)\times f(6)\in\{1, 2, 4\}$이다. (i) $f(1)=1, f(6)=1$일 때: $2\le f(2)\le f(3)\le f(4)\le f(5)\le 2$이므로 $1$개 (ii) $f(1)=1, f(6)=2$일 때: $2\le f(2)\le f(3)\le f(4)\le f(5)\le 4$이므로 ${}_3\mathrm{H}_4 = {}_6\mathrm{C}_4 = 15$개 (iii) $f(1)=1, f(6)=4$일 때: $2\le f(2)\le f(3)\le f(4)\le f(5)\le 6$ (공역이 $X$이므로 상한은 $6$)이므로 ${}_5\mathrm{H}_4 = {}_8\mathrm{C}_4 = 70$개 (iv) $f(1)=2, f(6)=2$일 때: $4\le f(2)\le f(3)\le f(4)\le f(5)\le 4$이므로 $1$개 따라서 구하는 함수 $f$의 개수는 $1+15+70+1=87$이다.
29. [확률과 통계 / 4점] 정답 38
▶ 출제의도 : 정규분포 곡선의 대칭성과 평행이동 성질을 이용하여 평균과 표준편차를 구할 수 있는가?
[풀이] 모든 실수 $x$에 대하여 $\mathrm{P}(X\le x)=\mathrm{P}(X\ge 60-x)$이므로 정규분포 곡선의 대칭축에서 $m_1=30$이다. 또한 모든 실수 $x$에 대하여 $\mathrm{P}(Y\le x)=\mathrm{P}(X\le x+12)$이므로 $$\dfrac{x-m_2}{\sigma_2} = \dfrac{x+12-30}{\sigma_1} = \dfrac{x-18}{\sigma_1}$$ 이 $x$에 대한 항등식이므로 $\sigma_1=\sigma_2$이고 $m_2=18$이다. $$\mathrm{P}(24\le X\le 30)+\mathrm{P}(24\le Y\le 30)$$ $$= \mathrm{P}\left(0\le Z\le \dfrac{6}{\sigma_1}\right) + \mathrm{P}\left(\dfrac{6}{\sigma_1}\le Z\le \dfrac{12}{\sigma_1}\right)$$ $$= \mathrm{P}\left(0\le Z\le \dfrac{12}{\sigma_1}\right) = 0.4332$$ 표준정규분포표에서 $\dfrac{12}{\sigma_1}=1.5$이므로 $\sigma_1=\sigma_2=8$이다. 따라서 $m_1+\sigma_2=30+8=38$이다.
30. [확률과 통계 / 4점] 정답 86
▶ 출제의도 : 독립시행에서 $6$의 눈이 나온 횟수에 따른 케이스 분류를 통해 확률을 구할 수 있는가?
[풀이] 초기 상태는 $\mathrm{H, H, H, T, T}$이다. $4$번의 시행에서 $6$의 눈이 나온 횟수를 기준으로 경우를 나눈다. (i) $6$의 눈이 $0$번 나온 경우: $4, 5$번째 동전은 홀수 번, $1, 2, 3$번째 동전은 짝수 번 뒤집혀야 한다. - $\{4, 5\}$ 중 하나가 $3$번, 다른 하나가 $1$번 나오는 경우: $2\times\dfrac{4!}{3!1!}=8$가지 - $4, 5$가 각 $1$번씩 나오고 $\{1, 2, 3\}$ 중 하나가 $2$번 나오는 경우: $3\times\dfrac{4!}{2!1!1!}=36$가지 (ii) $6$의 눈이 $1$번 나온 경우: 전체가 한 번 뒤집히므로 $1, 2, 3$번째 동전이 각 $1$번씩 뒤집혀야 한다. 즉 눈의 수 $1, 2, 3, 6$이 각 $1$번씩 나오는 경우의 수는 $4!=24$가지이다. (iii) $6$의 눈이 $2$번 나온 경우: 전체가 두 번 뒤집혀 원상복구되므로 남은 $2$번 동안 $4, 5$의 눈이 각 $1$번씩 나와야 한다. 즉 $\{4, 5, 6, 6\}$을 나열하는 경우의 수는 $\dfrac{4!}{2!1!1!}=12$가지이다. (iv) $6$의 눈이 $3$번 또는 $4$번 나온 경우: 모두 앞면이 될 수 없다 ($0$가지). 따라서 구하는 확률은 $\dfrac{8+36+24+12}{6^4}=\dfrac{80}{1296}=\dfrac{5}{81}$이므로 $p+q=81+5=86$이다.
