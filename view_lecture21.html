📐 수학적 원리 & 8칸 황금 비율 유도

1. 삼각함수 1주기의 8칸 분할 구조

$y = A \sin(\omega x) + B$의 기본 주기 $T = \frac{2\pi}{\omega}$는 $x$축 방향으로 $4$등분되어 각 구간의 길이는 $\frac{T}{4}$가 됩니다. 진폭 $A$에 의해 세로 방향으로 $2$등분되므로, 전체 1주기는 $4 \times 2 = 8$칸의 직사각형 매트릭스로 분할됩니다.

2. 높이 절반($y = A/2$)의 $1 : 2$ 가로 분할 증명

원점 $(0,0)$에서 극대점 $(\pi/2, 1)$까지의 1사분면 구간에서:

$$\sin x = \frac{1}{2} \iff x = \frac{\pi}{6} = \frac{1}{3} \times \frac{\pi}{2}$$

따라서 원점부터 $x = \pi/6$까지의 거리는 $1$단위이고, $x = \pi/6$부터 대칭축 $x = \pi/2$까지의 거리는:

$$\frac{\pi}{2} - \frac{\pi}{6} = \frac{2\pi}{6} = \frac{\pi}{3} = 2\text{단위}$$

즉, 가로 길이가 정확히 $1 : 2$로 내분됩니다!

3. 높이 $\frac{\sqrt{3}}{2}$의 $2 : 1$ 가로 분할 증명

$$\sin x = \frac{\sqrt{3}}{2} \iff x = \frac{\pi}{3} = \frac{2}{3} \times \frac{\pi}{2}$$

원점에서 $2$단위, 극대점까지 $1$단위이므로 $2 : 1$ 내분이 성립합니다.
