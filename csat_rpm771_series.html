[문항] 실수 $x$에 대하여 함수 $g(x)$를 다음과 같이 정의한다.
$$g(x) = \int_{x}^{x+2} (3t^2 - 12t + 9) \, dt$$ 닫힌구간 $[0, 4]$에서 함수 $g(x)$가 극값을 갖는 $x$의 값을 모두 구하고, 최댓값 $M$과 최솟값 $m$의 합 $M + m$을 구하시오.
📌 1단계: 출제 의도 및 조건 분석 (RPM 771 원리)
피적분함수 $f(t) = 3t^2 - 12t + 9 = 3(t-1)(t-3)$입니다.
폭이 $2$인 구간 $[x, x+2]$가 이동하면서 만들어내는 정적분 값 $g(x)$의 증감을 파악해야 합니다.
⚡ 2단계: 미분을 통한 증감 조사
미적분의 기본정리에 의해 도함수는 다음과 같습니다:
$$g'(x) = f(x+2) - f(x)$$ $$f(x+2) = 3(x+1)(x-1) = 3x^2 - 3$$ $$f(x) = 3x^2 - 12x + 9$$ $$g'(x) = (3x^2 - 3) - (3x^2 - 12x + 9) = 12x - 12 = 12(x - 1)$$ 따라서 $g'(x) = 0$이 되는 점은 $x = 1$뿐이며, $x=1$에서 극솟값을 가집니다!
🎯 3단계: 닫힌구간 $[0, 4]$에서의 최대·최소 및 정답
경계값 및 극값 계산:
• $x = 0$ : $g(0) = \int_0^2 (3t^2 - 12t + 9) dt = [t^3 - 6t^2 + 9t]_0^2 = 8 - 24 + 18 = 2$
• $x = 1$ (극소) : $g(1) = \int_1^3 (3t^2 - 12t + 9) dt = [t^3 - 6t^2 + 9t]_1^3 = 0 - 4 = -4$
• $x = 4$ : $g(4) = \int_4^6 (3t^2 - 12t + 9) dt = 54 - 4 = 50$
따라서 최솟값 $m = g(1) = -4$, 최댓값 $M = g(4) = 50$
정답: $M + m = 46$

$f(x) = -x^2 + 4x$의 꼭짓점(대칭축)은 $x = 2$입니다.
길이가 $1$인 구간 $[t, t+1]$이 이동할 때 대칭축 $x=2$의 포함 여부에 따라 최댓값 $M(t)$의 식 분기:
⚡ 2단계: 구간별 $M(t)$ 유도

$$M(t) = f(2) = 4$$ ③ $t > 2 \implies 2 < t \le 3$ : 감소구간이므로 왼쪽 끝 $x=t$에서 최대
$$M(t) = f(t) = -(t-2)^2 + 4 = -t^2 + 4t$$
🎯 3단계: 둘러싸인 넓이 계산
$S = \int_0^1 (-t^2 + 2t + 3) dt + \int_1^2 4 dt + \int_2^3 (-t^2 + 4t) dt$

• $\int_1^2 4 dt = 4$
• $\int_2^3 = [-\frac{t^3}{3} + 2t^2]_2^3 = (-9 + 18) - (-\frac{8}{3} + 8) = 9 - \frac{16}{3} = \frac{11}{3}$
따라서 총 넓이 $S = \frac{11}{3} + 4 + \frac{11}{3} = \frac{34}{3}$
정답: $\frac{34}{3}$

[문항] 실수 $x$에 대하여 함수 $g(x)$가 다음과 같이 정의된다.
$$g(x) = \int_{x}^{x+1} (4t^3 - 4t) \, dt \quad (-1 \le x \le 1)$$ 함수 $g(x)$의 최댓값을 $M$, 최솟값을 $m$이라 할 때, $M - m$의 값을 구하시오.
📌 1단계: 미분과 도함수 인수분해
피적분함수 $f(t) = 4t^3 - 4t = 4t(t-1)(t+1)$은 원점 대칭(기함수)입니다.
양변을 $x$에 대해 미분하면:
$$g'(x) = f(x+1) - f(x) = [4(x+1)^3 - 4(x+1)] - [4x^3 - 4x]$$ $$= 4(3x^2 + 3x + 1) - 4 = 12x^2 + 12x = 12x(x + 1)$$
⚡ 2단계: 극대·극소 판정
$g'(x) = 12x(x+1) = 0$ 에서 $x = -1, 0$.
• $x = -1$ : 부호가 $+$에서 $-$로 바뀌므로 극대 (구간 경계)
• $x = 0$ : 부호가 $-$에서 $+$로 바뀌므로 극소
🎯 3단계: 정적분 계산 및 최대·최소 차이
부정적분 $F(t) = t^4 - 2t^2$ 라 하면 $g(x) = F(x+1) - F(x)$입니다.
• $g(0) = F(1) - F(0) = (1 - 2) - 0 = -1$ (극소이자 최소: $m = -1$)
• $g(-1) = F(0) - F(-1) = 0 - (1 - 2) = 1$
• $g(1) = F(2) - F(1) = (16 - 8) - (-1) = 9$ (경계이자 최대: $M = 9$)
따라서 최댓값 $M = 9$, 최솟값 $m = -1$
정답: $M - m = 9 - (-1) = 10$

[문항] 실수 $x$에 대하여 함수 $g(x) = \int_{x-1}^{x+1} (-t^3 + 3t) \, dt$ 가 정의된다.
함수 $g(x)$의 극댓값을 $A$, 극솟값을 $B$라 할 때, $A^2 + B^2$의 값을 구하시오.
📌 1단계: 중심이 $x$이고 폭이 2인 대칭 윈도우 미분
피적분함수 $f(t) = -t^3 + 3t$에 대하여 윈도우는 $[x-1, x+1]$입니다.
$$g'(x) = f(x+1) - f(x-1)$$ $f(t)$가 기함수($f(-t) = -f(t)$)임을 활용하면:
$$f(x+1) - f(x-1) = [-(x+1)^3 + 3(x+1)] - [-(x-1)^3 + 3(x-1)]$$ 전개하면 $-(6x^2 + 2) + 6 = -6x^2 + 4 = -6\left(x^2 - \frac{2}{3}\right)$
⚡ 2단계: 극값의 위치와 부호 분석
$g'(x) = 0 \iff x = \pm \sqrt{\frac{2}{3}}$
$g'(x)$는 위로 볼록한 이차식이므로:
• $x = -\sqrt{\frac{2}{3}}$ 에서 극소 ($B$)
• $x = \sqrt{\frac{2}{3}}$ 에서 극대 ($A$)
또한 피적분함수가 기함수이므로 정적분 함수 $g(x)$는 기함수입니다! 즉 $B = -A$.
🎯 3단계: 극값 계산 및 $A^2 + B^2$
$g(x) = \int_{x-1}^{x+1} (-t^3 + 3t) dt = \left[-\frac{t^4}{4} + \frac{3t^2}{2}\right]_{x-1}^{x+1} = -2x^3 + 4x$
극대점 $x = \sqrt{\frac{2}{3}}$ 대입:
$$A = g\left(\sqrt{\frac{2}{3}}\right) = -2 \cdot \frac{2}{3}\sqrt{\frac{2}{3}} + 4\sqrt{\frac{2}{3}} = \frac{8}{3}\sqrt{\frac{2}{3}}$$ 따라서 $A^2 = \frac{64}{9} \cdot \frac{2}{3} = \frac{128}{27}$
$B = -A$ 이므로 $A^2 + B^2 = 2A^2 = \frac{256}{27}$
정답: $\frac{256}{27}$
💡 수능 킬러 아이디어: 윈도우 $[x-k, x+k]$의 도함수 $g'(x) = f(x+k) - f(x-k)$는 $f(t)$의 그래프에서 두 점 $(x+k, f(x+k))$와 $(x-k, f(x-k))$의 높이가 같아지는 순간 평균변화율이 0이 됨을 의미합니다.
