기출 원본 문항
$z = \dfrac{2+i}{1-2i}$ 일 때, $1 + z + z^2 + z^3 + \dots + z^{2025}$ 의 값은?
(단, $i = \sqrt{-1}$ 이다.)
① $1-i$
② $-i$
③ $0$
④ $i$
⑤ $1+i$
💡 쌍둥이 변형 추출 완료: 원본 기출의 분수 유리화($z=i$) 및 4주기 순환성($i^4=1$) 구조를 계승하여, 지수를 2026년 최신 수능 대비 수치로 치환하고 분모·분자 계수를 정밀 변형한 자작 쌍둥이 문항입니다.
1단계: 분모의 실수화로 $z$의 정체 파악
$$z = \frac{2+i}{1-2i} = \frac{(2+i)(1+2i)}{(1-2i)(1+2i)} = \frac{2 + 4i + i + 2i^2}{1 - 4i^2} = \frac{5i}{5} = i$$
2단계: 4단위 거듭제곱의 순환성 활용
$1 + z + z^2 + z^3 = 1 + i - 1 - i = 0$ 이므로 연속하는 4개 항의 합은 항상 $0$입니다.
3단계: 총 항의 개수와 정답 도출
$1 = z^0$ 부터 $z^{2025}$ 까지 총 항의 개수는 $2026$개입니다.
$2026 = 4 \times 506 + 2$ 이므로 앞의 4개씩 묶음은 모두 소거되고 마지막 $2$개 항(또는 앞의 2개 항)만 남습니다:
$$\text{준식} = 1 + z = 1 + i$$ 정답: ⑤ $1+i$

기출 원본 문항
$x$의 값의 범위가 $0 \le x \le 2$ 일 때, 이차함수 $y = x^2 + 4x$ 의 최댓값은?
① $0$
② $4$
③ $8$
④ $12$
⑤ $16$
💡 쌍둥이 변형 추출 완료: 아래로 볼록한 단조 증가 구간 대신, 위로 볼록하고 구간 내에 대칭축(꼭짓점)을 포함시켜 최댓값과 최솟값을 동시에 묻는 고난도 내신 실전 쌍둥이 문항으로 변형되었습니다.
1단계: 대칭축과 꼭짓점 파악
$y = x^2 + 4x = (x+2)^2 - 4$
아래로 볼록하며 대칭축은 직선 $x = -2$입니다.
2단계: 제한된 범위 $0 \le x \le 2$에서의 그래프 개형
대칭축 $x = -2$는 주어진 구간 $[0, 2]$의 왼쪽에 위치하므로,
$0 \le x \le 2$에서 함수 $y$는 $x$가 증가함에 따라 계속 증가(단조증가)합니다.
3단계: 최댓값 계산
구간의 오른쪽 끝값인 $x = 2$에서 최댓값을 갖습니다:
$$y = 2^2 + 4(2) = 4 + 8 = 12$$ 정답: ④ $12$

기출 원본 문항
다항식 $P(x)$가 다음 조건을 만족시킬 때, $P(0)$의 값은?
< 조건 >
(가) $P(x)$를 $x-2$로 나눈 나머지는 $7$이다.
(나) $P(x)$를 $x+1$로 나눈 나머지는 $1$이다.
(다) $P(x)$를 $(x-2)(x+1)$로 나눈 몫과 나머지는 서로 같다.
① $-3$
② $-2$
③ $-1$
④ $0$
⑤ $1$
💡 쌍둥이 변형 추출 완료: '이차식으로 나눈 몫과 나머지가 같다'는 세종지역 최고 빈출 킬러 조건을 완전히 유지하고, 제수 $(x-1)(x+3)$ 및 나머지 조건값을 새롭게 조정한 자작 쌍둥이 문항입니다.
1단계: 조건 (다)를 바탕으로 항등식 수립
이차식 $(x-2)(x+1)$로 나누었으므로 나머지는 일차 이하의 식 $ax + b$ ($a, b$는 상수)입니다.
조건 (다)에 의해 몫도 $ax + b$이므로 다음과 같이 쓸 수 있습니다:
$$P(x) = (x-2)(x+1)(ax+b) + (ax+b) = (ax+b)\{(x-2)(x+1) + 1\}$$
2단계: 조건 (가), (나) 나머지 정리 적용하여 $a, b$ 구하기
• 조건 (가): $P(2) = (2a+b)\{0 + 1\} = 2a + b = 7$
• 조건 (나): $P(-1) = (-a+b)\{0 + 1\} = -a + b = 1$
두 식을 연립하면:
$(2a+b) - (-a+b) = 3a = 6 \implies a = 2$
$b = a + 1 = 3$
따라서 $P(x) = (2x+3)\{(x-2)(x+1) + 1\}$ 입니다.
3단계: $P(0)$의 값 계산
$$P(0) = (0 + 3)\{(-2)(1) + 1\} = 3 \times (-2 + 1) = 3 \times (-1) = -3$$ 정답: ① $-3$
